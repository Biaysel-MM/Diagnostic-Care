# Diagnostic Care 🏥

Plataforma web de diagnóstico inteligente de enfermedades. Analiza tus síntomas y recibe diagnósticos preliminares precisos mediante un sistema de coincidencia de síntomas.

## 🚀 Características

- **Análisis Básico** — Selecciona tus síntomas y obtén resultados inmediatos con porcentajes de coincidencia.
- **Análisis Profundo** — Formulario detallado con edad, sexo, presión arterial y más para un diagnóstico más preciso.
- **Catálogo de Enfermedades** — Explora enfermedades comunes con descripciones y niveles de gravedad.
- **Interfaz Moderna** — Diseño responsive con Vue 3 + Tailwind CSS v4.

## 🛠️ Tecnologías

- [Vue 3.5](https://vuejs.org/) (Composition API)
- [Vue Router 4](https://router.vuejs.org/) (hash-based routing)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Vite 6](https://vitejs.dev/)

## 📦 Instalación

```bash
npm install
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 📁 Estructura

```
src/
├── components/     # Componentes reutilizables (NavBar, FooterBar, DiseaseCard, etc.)
├── composables/    # Composición de lógica
├── data/           # Base de datos de enfermedades y síntomas
├── router/         # Configuración de rutas
├── utils/          # Utilidades de diagnóstico
└── views/          # Vistas (Home, Analisis, Basico, Profundo, Catalogo, Informacion)
```
